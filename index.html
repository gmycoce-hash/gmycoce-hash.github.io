Personal notification utility

Personal Mail Notify

本人が許可したGoogleアカウントから、本人が指定した宛先へ通知メールを送る個人用アプリです。

アプリの用途

所有者が用意した通知内容をメールで届けるために使用します。所有者本人が管理・利用するアプリです。

このウェブサイトは、アプリの用途とデータの扱いを説明する静的ページです。このページ上では認証やメール送信の操作を行いません。

Googleへのアクセスを求める理由

Gmailからの送信（gmail.send）
所有者が認可した送信用Googleアカウントから、本人が指定した固定の宛先へ通知メールを送るためです。
送信元の確認（openid・userinfo.email）
認可したGoogleアカウントのメールアドレスを確認し、意図した送信元と一致するかを確かめるためです。

受信メールの読み取り・削除や、Googleドライブなど他サービスへのアクセスは求めません。Googleの認可画面は所有者自身が確認・操作します。

データの扱い

Googleの認可情報は所有者が管理する環境内に暗号化して保存し、アクセスを制限します。Googleとの通信にはHTTPSを使います。通知メールには送信目的に必要な情報だけを含め、認可情報は含めません。

本アプリによるGoogleユーザーデータの使用と転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

詳しくはプライバシーポリシーをご覧ください。

連絡先・認可の解除

個人利用のため、管理・問い合わせ先はGoogleの同意画面に表示されるユーザーサポートメールです。所有者はGoogleアカウントの接続設定から本アプリへのアクセスを取り消せます。
